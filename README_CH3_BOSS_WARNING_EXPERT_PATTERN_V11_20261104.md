# Chapter 3 Degreeon Boss — V11 Warning & Expert Pattern Patch

기준: V10 Shift 폭탄 / 사격 지원몹 패치가 적용된 프로젝트

## 반영 사항 (요청 1~9)

1. **외곽 로켓**: 기존 보라색의 얇은 경고선을 검정 외곽선 + 밝은 황백색 점선(약 4.6 px)으로 교체합니다. 로켓의 실제 충돌 너비에 대응하는 진행 경로도 반투명으로 예고합니다.
2. **파동 레이저**: 경고 영역을 황금빛 반투명으로 채우고 테두리에는 9 px 어두운 윤곽 + 5 px 밝은 점선을 사용합니다. 7레인 중 6개 위험 레인을 빈틈 없이 채우도록 충돌 영역을 레인 폭의 104%로 변경했습니다. 남은 안전 레인은 민트색으로 구분합니다. 실제 피격 영역과 표시 영역이 맞도록 레이저 본체도 전체 판정 폭을 밝힙니다.
3. **거울 레이저**: 예고 경로 전체를 어두운 굵은 테두리 + 황백색 점선으로 표시합니다. 기존 반사 타이밍과 공격 경로는 유지합니다.
4. **오염 낙뢰**: 예고 경로를 어두운 외곽선(9 px)과 밝은 황백색 점선(4.4 px)으로 강화합니다. 실제 낙뢰 판정과 예고 경로를 일치시킵니다.
5. **졸업 도장 숙련(3·4단계)**: 전체화면 여부와 관계없이 연속 날인을 사용합니다. 도장 착지 → 들어 올리기(약 0.45초) → 약 1초 후 다음 타격(경고 포함)이 이어지게 합니다. 기존 일반 난이도의 단발 및 전체화면 동작은 유지합니다.
6. **오염 낙뢰 숙련(3·4단계)**: 서로 분리된 낙뢰가 한 번에 2개와 3개 번갈아 떨어집니다. 발사 간격은 각각 약 0.51초 / 0.43초로 단축합니다. 기존 1·2단계는 두 번의 낙뢰를 차례로 내리는 구조를 유지합니다.
7. **파동 레이저 가로**: 기존 발사 간격 1.35초 / 1.22초를 1.80초 / 1.62초(최종 단계)로 연장했습니다. 세로 레이저의 발사 간격은 변경하지 않습니다.
8. **졸업 검수 시선**: 수평으로 늘어선 낙하탄의 반지름을 7 px에서 13 px로 키우고 색상을 황백색으로 변경합니다. 일반은 중앙 시선 1개, 숙련은 좌우 시선 2개입니다. 각 시선은 공격 후에도 바라보던 각도와 진행 방향을 유지하고, 다음 시선 패턴에서 다시 등장해도 이전 진행 방향을 이어갑니다.
9. **전장 분할 안전 피신 숙련**: 3단계/4단계 경고 시간을 각각 약 1.31초/1.04초로 단축하고 폭발 및 재시작 간격도 단축합니다. 일반 1·2단계는 기존 시간 유지합니다.

10번 항목은 요청 본문에 세부 내용이 없어 변경하지 않았습니다.
