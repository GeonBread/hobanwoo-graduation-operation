# 챕터 3 디그리온 보스전 BGM 교체 패치 V9

## 적용 내용

1. **장면 20 최종 공간**에서 호반우의 마지막 대사인 **“그래도 난 졸업할 거야.”** 이후 진행되는 **18초 보스전 진입 연출**이 시작되면 기존 최종 공간 BGM의 볼륨이 **8초에 걸쳐 0으로 감소**합니다.
2. 연출이 끝나고 **실제 디그리온 보스전이 시작되면** 제공하신 `Starfall Circuit.mp3` 원본을 재생하고 루프합니다. 보스전 직접 실행 및 테스트 실행에서도 동일하게 적용됩니다.
3. 보스전 클리어 후 장면 29로 복귀하면 기존 최종 공간 BGM을 다시 재생합니다. 보스전/챕터 선택 화면을 이탈하면 새 보스 BGM은 정리됩니다.
4. 기존 보스 공격 패턴, 대사·폰트, 화면 및 나머지 스토리 BGM은 변경하지 않았습니다.

## 프로젝트 파일

- `src/components/story/Chapter3StoryExperience.tsx` — 장면 20 연출 중 스토리 BGM 페이드 및 이후 BGM 복귀
- `src/components/story/Chapter3BossBattle.tsx` — 디그리온 보스전에서 새 BGM 호출 및 정리
- `src/game/AudioSystem.ts` — 보스전 전용 BGM 재생 기능
- `public/assets/audio/chapter3/starfall-circuit.mp3` — 사용자 제공 MP3 원본(무변환)

## 적용 방법

`APPLY_PATCH.cmd`에 ZIP 파일을 드래그해 적용합니다. 프로젝트 루트에 상대경로 그대로 복사하는 패치이므로 ZIP에 있는 MP3도 함께 적용해야 합니다.

## 검증 범위

- MP3 길이와 메타데이터 점검 및 SHA-256 원본 일치 검증
- `AudioSystem.ts` 독립 타입 검사, 변경 TSX 구문 변환
- 모의 브라우저 오디오에서 반복 재생·볼륨·페이드·재시작·정지 확인
- `git diff --check` 통과 및 ZIP 무결성 검사
- 전체 프로젝트 빌드 및 실제 플레이 오디오 출력은 로컬 의존성/실제 리소스 환경의 제약으로 직접 검증하지 못했습니다.
