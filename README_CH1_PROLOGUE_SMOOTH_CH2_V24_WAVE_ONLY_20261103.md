# 호반우의 졸업 대작전 V5 – 프롤로그 시네마틱 개선 + 챕터 2 웨이브 v24 이식

기준 프로젝트: 사용자가 올린 2026-11-03 AI_CONTEXT, 이전에 적용한 V4 나레이터/코어/크레딧 수정 버전.

## 1. 챕터 1 프롤로그

- `core-approach` (3.1초): 검은 화면의 이전 장면을 첫 프레임에 이어 받고, 별빛 터널의 이동·발광을 완만하게 가속/감속합니다.
- 터널이 끝난 장면을 정확히 복사해 `core-reveal` 첫 프레임에 겹쳐 놓은 뒤 1.28초 동안 서서히 전환합니다. 기존 첨성대 코어 밝아짐 연출은 이후 이어집니다.
- 균열은 전체화면 실제 캔버스를 기준으로 중심에서 시작합니다. 주 균열 12개를 지그재그로 생성해 네 모서리와 상하좌우 경계를 완전히 가로지르도록 했습니다.
- 화면 파편은 바로 그 균열 경로를 경계로 생성한 12개 다각형입니다. 각 조각이 원래 화면을 품은 채 독립적으로 회전·낙하합니다. 균열과 실제 깨지는 조각의 경계가 일치합니다.
- 이전 V4의 나레이터 전용 대사창, 오프닝 크레딧, 화면 전환, 버튼 동작을 유지합니다.

## 2. 챕터 2 웨이브만 이식

- 사용자 제공 `Hobanwoo_Ch2_Waves_v24_Images_BGM.zip` 안의 시뮬레이터에서 24개 웨이브 배치·적 이동·공격·공격 예고·보조 효과·진행 순서를 가져와 기존 `chapter2WaveSystem.ts`에 연결했습니다.
- 챕터 2 스토리/테스트 메뉴의 웨이브 선택 범위도 1~24로 변경했습니다.
- **기존 코드와 동일하게 유지한 것**: 플레이어 체력/피격 처리 호출, 플레이어 발사체, 폭탄 파동의 제거 처리, 정화 게이지 계산과 HUD 그림, 기존 스크롤 배경 `chapter2_wave_map.png`, 구름/파편 패럴랙스, 게임 오디오 연결.
- 별도 적/탄 이미지나 시뮬레이터용 배경/BGM/플레이어 UI는 복사하지 않습니다. 프로젝트에 이미 있는 에셋 경로를 그대로 사용합니다.
- 시뮬레이터에서만 구현된 적 보호막·파괴 가능한 장애물 등은 그 웨이브 고유 공격으로 연결하되 플레이어 HP 및 폭탄 시스템은 변경하지 않았습니다.

## 적용 방법

1. 원래 프로젝트의 백업을 만들어 둡니다.
2. ZIP의 `src` 폴더를 원래 프로젝트 최상위 폴더에 병합하여 같은 파일명에 덮어씁니다.
3. 다른 소스, 이미지, 음악, 설정은 삭제하거나 바꾸지 않습니다.
4. 기존 V4 수정이 적용된 프로젝트를 기준으로 하므로 적용 순서는 V4 -> V5입니다.
