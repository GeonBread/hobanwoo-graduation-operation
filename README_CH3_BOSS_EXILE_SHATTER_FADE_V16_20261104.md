# 챕터 3 디그리온 보스 – 추방 대폭발 및 전장 복귀 연출 V16

**기반 버전:** V15 패치가 적용된 게임 프로젝트

## 주요 수정
1. `게임 화면 밖 추방` 제한시간 초과 시 대폭발 전체 연출 시간을 4초에서 **3초**로 단축했습니다.
2. 이전에는 경계선이 17px 검정 외곽선과 겹친 보라 선으로 중복 그려지던 문제를 제거했습니다. 새 균열선은 얇은 2.8px 암부와 1.15px 보라색 강조선만 사용합니다.
3. **14개 조각이 동일한 지그재그 절단 경로를 공유**합니다. 실제 조각의 클리핑 경계와 발광 균열선이 정확히 일치합니다.
4. 공간 조각마다 분리 속도·회전 각도·중력 낙하를 다르게 부여했습니다. 화면 곳곳에서 오염 폭발이 계속 발생합니다.
5. 3초 종료 직전 화면을 **완전히 검정으로 페이드아웃**하고, 보스 전장은 검은 화면에서 약 1.4초 동안 자연스럽게 나타나며, 약 1.65초 후 다음 패턴으로 이어집니다.
6. 제한시간(일반 20초/숙련 15초), LIFE 1회 강제 차감, 숙련 오염 덩어리의 조준탄, 정상 포탈 귀환은 기존 동작을 유지합니다.
7. 제한시간 초과 폭발 도중에는 설명 텍스트가 표시되지 않습니다.
