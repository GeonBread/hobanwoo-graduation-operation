# 호반우의 졸업 대작전: 챕터 1 스토리 · 정화율 수정 패치

기준: 2026-11-07 `sky-strike-retro-ace` 소스 스냅샷

## 적용
이 ZIP을 압축 해제하고 **안에 있는 `src` 폴더를 프로젝트 최상위 폴더의 `src`에 덮어쓰기**하세요. 상대경로를 유지해야 합니다. `public/assets` 등의 이미지·음원 파일은 삭제하거나 교체하지 마세요.

> 이 파일은 챕터 1의 수정 소스만 포함한 덮어쓰기용 패치입니다. 전체 게임 프로젝트나 이미지 리소스를 포함하지 않습니다.

## 변경 내용

1. **학생증 발화에 놀라는 순간: 전체 화면 강한 단발 진동**
   - 대사 `말을.. 하잖아!!`의 화면 흔들림을 작은 스토리 스테이지용 클래스에서 브라우저 본문 전체를 흔드는 840ms 단발 충격으로 교체했습니다.
   - 이전 장면의 흔들림이 이후 장면에 남지 않도록 종료 시 애니메이션을 정리합니다.

2. **첫 번째 어색한 대사 수정**
   - 변경 전: `나는 학생증이 연결돼서 저 오염된 것들까지 직접 볼 수 있다는 거네?`
   - 변경 후: `그러니까 학생증 덕분에 나만 저 오염된 것들을 직접 볼 수 있다는 거네?`

3. **두 번째 어색한 대사 수정**
   - 변경 전: `그냥 하필 오늘 오염에 제대로 휘말려서 이게 켜진 거네?`
   - 변경 후: `그냥 오늘 오염에 휘말리는 바람에 학생증이 반응한 거네?`

4. **정화율 100% 이후 피격 무효**
   - 마지막 웨이브 종료 전 99.x%가 반올림되어 100%로 조기에 표시되지 않도록 계산을 수정했습니다.
   - 웨이브 최종 완료 즉시 무적 상태를 부여하고 잔여 적탄을 제거합니다.
   - 모든 일반 충돌 경로와 플레이어 HP 감소 함수에서 마지막 웨이브 완료 이후 피해·피격 연출을 차단합니다.
   - 스토리 TEST 메뉴에서 100% 연출로 직접 이동한 경우도 보호합니다.

5. **`학사 코어 영역` 장소명 단독 표시**
   - 코어 진입 후 전체화면 장소명 연출에서 제목 한 줄만 표시합니다. 아래쪽 별·코어 부제는 표시하지 않습니다.

6. **별 회수 이후 학생증 말투 정상화**
   - `별 회수 완료`, `코어 연결 기능 복구`, `이동 기능 복구`, `추가 오염 안내`의 학생증 대사를 챕터 2처럼 완결된 문장으로 수정했습니다.
   - 기존 대사 순서와 장면 진행을 유지하도록 총 27개 메시지 수는 변경하지 않았습니다.

## 확인 사항
- 변경된 TypeScript/TSX 9개 파일 구문 분석 및 TS→JS 변환 통과
- 내장 스토리 JavaScript 구문 분석 통과
- 대사 문구/스타 회수 대사/전체 화면 흔들림 호출/장소명 연출 연결 검사 통과
- 피격 함수 분리 실행 테스트: 완료 전 HP 3→2, 완료 후 HP 3 유지
- 정화율 100% 조기 표시 차단 및 TEST 직접 진입 보호 코드 검사 통과

원본 게임의 이미지·음원·`node_modules`가 없는 소스 스냅샷을 기준으로 작업했으므로, 전체 게임 실행·전투 플레이·브라우저 시각 검사는 수행하지 못했습니다.
