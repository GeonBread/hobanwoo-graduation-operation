### [챕터 2] 도서관 자리 연장 알림 연출 (#232)
사용자 첨부 이미지 기반으로 **실제 좌석배정확정 화면 느낌의 UI** 로 재구성.

#### 1) UI 변경
기존 단순 앱 알림형 화면 → 실제 KNU 좌석배정확정 화면 스타일로 변경:
- 빨간 상단 헤더 `좌석배정확정`
- 안내 문구 박스
- 좌석정보 / 이용상태 / 입실시간 / 퇴실시간 / 연장가능 횟수 / 연장가능시간 행 구성
- 하단 버튼 영역 포함

#### 2) 시간 관련 정보 재작성
스토리 연출용으로 시간 정보를 새로 구성.

#### 3) 연장 가능시간 3회 강조
`연장가능시간` 행에 대해:
- 행 배경 강조
- 외곽선 펄스
- 빨간 포인트 점 펄스
- 하단 연장 버튼 펄스

위 강조가 **3회 반복**되도록 추가.

#### 4) 연출 시간 연장
기존 3900ms → **6200ms** 로 늘려서
강조 3회가 보인 뒤 다음 대사로 넘어가도록 조정.
