## 적용 방법 (Windows)

1. 기존 프로젝트 디렉터리를 **백업**하거나 Git 커밋을 만들어 주세요.
2. 이 ZIP 파일을 압축 해제합니다.
3. 압축 해제한 폴더에 있는 **`src` 폴더 전체를 원본 `sky-strike-retro-ace` 프로젝트 최상위 디렉터리로 복사**하고 같은 이름의 파일 덮어쓰기를 승인합니다.
4. `public/assets` 아래 PNG/WebP/MP3/WOFF 등 기존 바이너리 리소스는 **그대로 보존**합니다.
5. 프로젝트에 종속성(`node_modules`)이 이미 설치되어 있다면 프로젝트 루트에서 `npm run lint`, `npm run build`를 실행해 주세요.

이 패치는 완전한 게임 배포본이 아니며, **기존 프로젝트 파일 4개만 교체**합니다. ZIP 내 `src/`를 통째로 지우거나 다른 파일을 제거하지 마세요.

## 원본 에셋과 중복 일러스트 처리

`#183`과 `#184`의 **사용 포즈는 통일**했습니다. 다만 원본 AI_CONTEXT ZIP에는 PNG/WEBP 같은 바이너리 이미지가 포함되지 않고 **파일명 목록만 포함**되어 있어 실제 이미지 두 장이 픽셀 단위로 동일한지 검증할 수 없습니다. `hobanwoo_pose_explaining.png`, `hobanwoo_pose_presenting.png` 등은 다른 대화 장면에서도 쓰이므로 **실제 에셋 파일은 삭제하지 않았습니다**. 검증 없이 삭제하면 해당 장면들이 깨질 수 있기 때문입니다.

도서관 좌석 화면은 실제 휴대폰 캡처나 앱 리소스가 아닌 **이용 메뉴 구조를 바탕으로 자체 제작한 모의 UI**입니다. 학교가 제공한 최신 앱의 화면과 레이아웃이 완전히 같다고 보장하지 않습니다.
