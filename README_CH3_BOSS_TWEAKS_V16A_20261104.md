# CH3 Boss Patch v16A (2026-11-04)

반영 내용

1. 메인화면 사기 2번째(몬스터 등장)
- 혼합 웨이브 몬스터 표시 크기 대폭 확대(대략 기존 대비 2배 수준)
- 피격 판정/폭탄 판정도 확대된 시각 크기에 맞게 보정
- 챕터별 투사체 비주얼 차별화(1장 orb / 2장 dart / 3장 shard)
- 투사체 크기 및 가시성 강화

2. 전장 밖의 손
- 예비선 점선/하이라이트 강화
- 실제 이동 영역(fill + 외곽선 + 내부 가이드 라인) 가시성 강화

3. 지나온 길이 접힌다
- 2페이즈 전용 보조공격으로 이동: phaseTwoScore에서 단독 특수 패턴 제거, volley-cross에 support로 연결
- 예고 선을 더 확실한 점선으로 조정
- 접힘 후 잔상 제거
- 접힘 연출을 지그재그/지퍼형으로 강화
- 연속 동작이 더 부드럽게 이어지도록 조정

4. 지오메트리 패턴
- 중력 방향 표시는 화면 회전이 끝난 뒤에만 표시되도록 조정
- 표시 디자인을 더 세련된 판넬형으로 수정
- 바닥 불길을 둥근 모양 대신 날카로운 flame 형태로 수정

5. 오염 액체 범람
- 액체가 본격적으로 완전 범람한 뒤에만 난전 타이머 시작
- 일반 모드: 완전 범람 후 약 10초 지속
- 숙련 모드(3/4단계): 완전 범람 후 12~17초 랜덤 지속
- 범람 이후 탄막 밀도 상향
- 플레이어 탄 저항은 액체 내부(submerged)에서만 적용되도록 수정
