## 요청 2 · 챕터 3 최종 엔딩 크레딧

- 마지막 `THANK YOU FOR PLAYING` 화면의 퇴장 애니메이션이 완료되면 메인화면(MENU)으로 이동합니다.
- 애니메이션 종료 이벤트와 110초 백업 타이머가 **같은 한 번만 실행되는 완료 함수**를 호출합니다.
- 테스트 이동(F7)에서 크레딧을 실행한 경우에도 스토리 선택창이 아닌 메인화면으로 복귀합니다.
- 정상 플레이에서는 기존 완료 기록 저장 후 메인화면 이동을 유지합니다.
- 엔딩 크레딧 도중 뒤늦게 전달되는 스토리 진행 메시지가 엔딩 BGM을 덮어쓰지 않도록 막았습니다.

## 요청 3 · 챕터 2 보스전 전환

기존 붉은 셔터/흰 대각선/경고 배너를 사용하지 않는 **4초간의 독립적인 보라색 블랙홀 시네마틱**으로 교체했습니다.

- 우주/중력장 생성 → 문서 및 PPT 자료가 소용돌이로 흡수 → 사건의 지평선과 타이틀 등장 → 수축 섬광 및 검은 화면으로 종료
- 기존 `storyBossEmergenceActive`(스토리 중 보스를 처음 마주치는 장면)의 보라색 문서 흡수 연출은 **그대로 보존**했습니다.
- 현재 스토리 BGM은 보스 전환에 들어가는 순간부터 2.7초 동안 부드럽게 볼륨이 내려갑니다.
- 전환의 남은 1.3초는 무음이며 **전투 실제 시작 시점(4초 뒤)에만 보스 BGM**이 시작됩니다.
- 보스 패턴 직접 테스트 점프는 기존처럼 바로 전투로 이동합니다.
