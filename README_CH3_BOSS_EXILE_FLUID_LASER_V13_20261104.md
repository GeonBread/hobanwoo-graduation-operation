# 챕터 3 디그리온 보스전 V13 패치

적용 전제: V12 패치까지 적용한 게임 프로젝트의 최상위 폴더.

## 1. 파동 레이저 (가로)
- 일반/숙련 모두 기존보다 발사 간격을 0.3초 증가시켰습니다.
- 이전: 기본 1.80초, 최고 숙련 1.62초.
- 변경: 기본 2.10초, 최고 숙련 1.92초.
- 세로 레이저 간격은 유지합니다.

## 2. 게임 화면 밖 추방
- 조작 가능한 추방 공간에 진입한 순간부터 시간 제한을 시작합니다.
- 일반(단계 0~1): **20초** / 숙련(단계 2~3): **15초**.
- 남은 시간을 화면 상단 게이지와 숫자로 표시합니다.
- 제한시간 내 포탈에 들어가지 못하면 전체 추방 공간 폭발 연출이 발생합니다.
- 평소 피격 무적·폭탄 무적 지속 중에도 시간 초과 시 **LIFE를 정확히 1회, 1개 감소**시킵니다.
- LIFE가 남으면 폭발 연출 후 원래 보스 전장으로 복귀합니다. LIFE 0이면 GAME OVER입니다.
- 기존 초기 적 목표 수 112→168기, 유지 상한 128→192기로 약 1.5배 늘렸으며, 추가 출현 주기도 비례하여 단축했습니다.
- 숙련 단계에서는 기존 챕터 3 에셋인 `inspection_eye.png`, `file_carrier.png`를 사용하는 **원거리 조준탄 몬스터**가 추가됩니다. 일반 모드에서는 기존 돌진형 몬스터만 등장합니다. 기존 스마트 폭탄은 새 조준탄도 파동 범위 내에서 제거합니다.

## 3. 오염 액체 범람
- **일반/숙련** 모두 설정된 최대 수위 도달 전 오염탄이 발사되지 않습니다.
- **숙련**: 시계 방향 → 정지 → 반시계 방향 → 정지 등을 부드러운 가속·감속으로 반복하며, 멈춤 구간이 실제로 존재합니다.
- 패턴 단독 지속시간: 29→34초.
- 스토리 2페이즈 큐 지속시간: 22→27초.
- 유체 조작 및 물속 이동, 기존 맵과 보스 BGM은 그대로 유지합니다.
