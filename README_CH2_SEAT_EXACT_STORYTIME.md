# 챕터 2 #232 도서관 좌석 연장 알림 수정 (2026-11-08)

## 수정 내용

- 기존의 겹쳐 보이는 날짜 덧그림과 버튼을 가리는 강조 배지를 전부 제거했습니다.
- 제공된 실제 앱 화면의 안내/좌석정보/3개 버튼/하단 영역을 그대로 유지하면서, **날짜 및 시각 텍스트만 오염 없이 다시 조판**했습니다.
- 챕터 2 직전 대사에서 `2029-04-15 22:40`에 공부를 재개하는 타임라인을 확인하여 다음처럼 조정했습니다.
  - 상단 상태바 `23:50`
  - 입실 `2029-04-15 18:30:00`
  - 퇴실 `2029-04-16 00:00:00`
  - 연장 가능시간 `2029-04-15 22:00:00 ~ 2029-04-16 00:00:00`
  - 반납유예시간 `00:10` 유지
- 강조 효과는 실제 화면 좌표(945x2048 기준, 전체 화면 아래쪽 연장가능시간 행)로 정확히 이동했고, 약 1.12초 간격으로 **3회** 점멸하도록 변경했습니다.
- 원본과 같은 세로 화면 비율(`945:2048`) 유지. 휴대폰 전체와 하단 버튼들이 한 화면에 보입니다.
- 기존 `seat-expiry` 연출 지속시간(`6200 ms`) 및 이후 대사는 변경하지 않았습니다.
