# 호반우의 졸업 대작전 — Chapter 3 스토리·디그리온 패치

기준: `sky-strike-retro-ace-AI_CONTEXT-20261107-170216.zip` 의 소스 스냅샷.
압축파일은 *완성 게임*이 아니라 프로젝트 루트에 덮어쓰는 **수정 파일 전용 패치**입니다.

## 적용

1. 기존 프로젝트를 백업합니다.
2. ZIP을 압축 해제한 후 **ZIP 내부의 `src/` 폴더를 프로젝트 최상위 경로의 `src/`에 그대로 덮어씁니다.**
3. 원본 이미지/음악 폴더인 `public/assets/`는 삭제하거나 옮기지 마세요. 이 ZIP에는 원본 바이너리 에셋이 들어 있지 않습니다.
4. 개발 환경에서 `npm run dev` 또는 프로젝트의 기존 실행 명령으로 확인합니다.

### 확인 제한

- 제공된 원본 스냅샷은 이미지·음악·폰트 등 바이너리 에셋이 포함되지 않은 소스 전용 ZIP이므로,
  전체 프로젝트 빌드와 원본 이미지·사운드를 포함한 엔드투엔드 플레이 테스트는 이 작업 환경에서 수행하지 못했습니다.
- 일반 보스 전투 클리어 시 자동 이야기 복귀 코드는 연결했지만, 실제 전체 장시간 플레이는 별도 최종 확인이 필요합니다.
- 학사 기준/교과목명은 연출용 예시이며, 실제 경북대학교 또는 특정 학과의 공식 기준으로 확정한 정보가 아닙니다.
