# V6: Chapter 1/2 story dialogue and illustration sizes aligned to Chapter 3

기준: 2026-11-03 V5.1 패치와 기존 V4 나레이터 패치가 반영된 프로젝트.

## 적용 사항

- 챕터 3의 논리 스토리 화면(922x960)에 맞춘 **일반 대사창**의 높이/패딩/위치/텍스트 크기 통일.
- 챕터 1에서 대사창에 보이지 않는 초상화 격자열이 남아 텍스트 공간을 줄이던 문제 수정.
- 챕터 1 일반 캐릭터 이미지 슬롯을 챕터 3과 같은 비율로 조정.
- 챕터 1의 일반 중앙 컷 일러스트를 챕터 3과 같은 중앙 배치/비율로 조정.
- 챕터 2에도 챕터 3과 동일한 대사창/일러스트 비율 CSS를 명시하여 향후 충돌 방지. 기존 표시 비율은 이미 챕터 3과 일치했음.
- 나레이터 전용 대사창 디자인, 호반우 고유 스프라이트 슬롯, 보스/학생증/몬스터 전용 크기, 풀스크린 컷씬, 웨이브·전투 시스템은 유지.

## 챕터 3 기준 일반 대사창
- 좌우 여백: 3.5% / 화면 하단: 4.5%
- 최소 높이: `clamp(142px, 18vw, 202px)`
- 패딩: `clamp(30px, 3vw, 38px) clamp(26px, 3vw, 42px)`
- 글씨: Noto Sans KR ExtraBold 800, `clamp(18px, 2.3vw, 31px)`
- 일반 중앙 컷: 폭 `min(48%, 520px)` / 높이 `min(46%, 440px)` / `object-fit: contain`

- Chromium의 CSS 계산값 비교에서 CH1(파트1/파트2), CH2, CH3의 일반 대사창/중앙 일러스트/캐릭터 슬롯 크기가 1920x1080, 1366x768, 680x960 화면 크기에서 일치함.
- 나레이터 전용 태그·초상화 숨김 유지 확인.
- TypeScript 구문 변환 검사 정상.
- 전체 프로젝트 의존성 및 실제 게임 리소스가 없어 전체 빌드/연속 플레이 검증은 미실시.
