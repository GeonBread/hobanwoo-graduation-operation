# Chapter 1 Prologue – Corruption Center / Crack Depth / Fullscreen Opening Patch

## 적용 내용
1. **오염 시작 위치 중앙 정렬**
   - 챕터 1 프롤로그의 첫 오염(Seed/Growth/Burst) 연출 중심을 화면 정중앙으로 이동.
   - 균열 시작점도 동일한 중심점에서 발생하도록 조정.

2. **균열 연출 개선**
   - 기존 단순 평면 선형 균열을 다음과 같이 개편:
     - 중심 충격감 강화
     - 가지 균열 추가
     - 암부/보라광/밝은 균열선 3중 레이어 적용
     - 끝부분 발광 보강
   - 기존보다 덜 납작하고 더 입체적인 인상으로 조정.

3. **프롤로그 초반 경북대 배경 전체화면 확장**
   - Awakening / Campus / Sky / Gather / Threshold 구간을 코어 시네마틱과 동일하게 전체화면 연출로 표시.
   - 배경 이미지를 무리하게 왜곡하지 않고, 전체화면 시네마틱으로 보여주도록 변경.
