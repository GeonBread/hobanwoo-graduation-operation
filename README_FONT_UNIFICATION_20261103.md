# 호반우의 졸업 대작전 - 전체 폰트 통합 패치 (2026-11-03)

## 적용 대상
- 챕터 1, 2, 3 스토리 전체: 대사, 내레이션, 화자명, 장소명, 선택지, 자막, 크레딧, 로딩 및 진행 UI
- 챕터 3 보스 대사·시험/시네마틱 및 공통 메뉴·게임오버·랭킹 UI
- 독립 iframe의 챕터 2/3 스토리 및 챕터 3 웨이브 UI

## 표준 폰트
- 기본: Noto Sans KR ExtraBold (800)
- 큰 제목/화자명: Noto Sans KR Black (900)
- 일반 전투 및 메뉴: Noto Sans KR, 화면별 기존 굵기 유지
- 예외: 첨성대 코어/입학식 특수 타이틀의 CoreTitleSerif(합성 Bold), 디그리온 검은고딕(원래 Black 체)

## 폰트 제공 방법
- Google Fonts를 통해 Noto Sans KR 700/800/900을 비차단 방식으로 로드하며, 별도 폰트 바이너리는 배포하지 않습니다.
- 오프라인에서는 맑은 고딕/Apple SD Gothic Neo/나눔고딕으로 대체됩니다. 시스템에 대체 폰트가 없으면 일반 sans-serif로 표시됩니다.
- 기존 400 Thin Noto Sans KR CSS import는 해제하고 해당 CSS 본문도 더 이상 잘못된 폰트를 등록하지 않도록 정리했습니다.

## 설치
- 기존 프로젝트를 백업한 다음, 패치 ZIP을 **프로젝트 루트**에 덮어쓰거나,
  기존 `tools/chapter1_patch_runner/APPLY_PATCH.cmd`에 ZIP을 드래그해 적용합니다.
- 폴더를 한 겹 더 만들어 복사하면 안 됩니다. `index.html`, `src/`, `public/`이 프로젝트 루트에 있어야 합니다.
- 패치에 이미지, 음원, 폰트 바이너리, package-lock.json, .env 파일을 포함하지 않습니다.
- 브라우저 캐시가 남으면 Ctrl+Shift+R로 새로고침해 주세요.

## 수정 범위 및 주의
- 텍스트 문구, 스토리 순서, 탄막/보스 로직, 일러스트 경로, 화면 비율은 변경하지 않았습니다.
- 일반 전투, 챕터 1/2/3 보스 및 Canvas 텍스트의 표준 서체도 Noto Sans KR로 바꿨습니다. 크기·좌표·전투 로직은 그대로 유지했습니다.
- 디그리온 특수 시네마틱의 Black Han Sans는 독립적인 고유 타이틀로 유지했습니다.
- 대체 폰트, 브라우저별 글자 폭 차이로 긴 문장의 자동 줄바꿈이 달라질 수 있습니다.
