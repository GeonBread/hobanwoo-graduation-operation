# CH3 디그리온 보스전 V12 수정 패치

적용 전제: 기존 V11 패치가 적용된 프로젝트.

## 변경사항

1. 아이템 디자인을 챕터 2 공통 아이콘과 맞춤
   - LIFE: 초록색 둥근 사각형, 검정 테두리, 흰색 십자 (38 x 38 기준)
   - POWER: 노란 마름모, 검정 테두리, 빨간색 P (40 x 40 기준)
   - 기존 아이템 드롭 55%, 회복 34% / 화력 66%, 획득 판정은 그대로 유지

2. 틈새 압박 탄막 난이도 완화
   - 양끝 압박탄: 행 간격 65 -> 118, 속도 170 -> 160
   - 회피용 상단/하단 열린 구간을 230 -> 최대 320으로 확대
   - 느린 탄벽: 가로 생성 간격 36 -> 50, 안전 통로 반폭 95 -> 135
   - 주변 특수 패턴, 보스 체력, 플레이어 아이템 드롭은 유지

3. 2페이즈 각성 후 디그리온 대사 교체
   - 이전: 화면 안에만 있으면 안전할 줄 알았나?
   - 변경: 너가 아는 것이 이 세상의 전부라고 생각하나?
   - 기존 대사 전달 방식과 글꼴 유지

4. 2페이즈 동일 패턴 반복 방지
   - 본편: 2페이즈 큐당 학습 단계 반복(4단계/2단계) 제거
   - 페이즈 2에 지정된 난이도(stage 2 또는 3)로 한 번만 실행
   - 4개 공격이 묶인 일반 탄막의 동일 묶음은 1회만 발사
   - 일반 패턴은 약 7.8초 이내에 전환을 요청하며, 이전 탄환이나 특수 화면의 귀환 연출이 남아 있을 경우 안전하게 완료 후 전환
   - 1페이즈의 학습 흐름과 별도 패턴 연습 모드는 유지
