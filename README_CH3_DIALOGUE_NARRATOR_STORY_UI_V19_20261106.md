# 챕터 1·2·3 공통 대사창 / 나레이터 / 챕터 3 보스 스토리 UI (V19)

기준: V18가 적용된 호반우 졸업 대작전 프로젝트

## 변경 사항

1. 챕터 1·2의 일반 대사창 크기와 글꼴 크기를 챕터 3의 기준에 맞춥니다. 전체 브라우저의 `vw`가 아니라 게임 스테이지의 `cqw`를 기준으로 지정하여 큰 화면에서도 챕터 1·2가 과도하게 커지지 않게 합니다.
2. 공통 나레이터 CSS(`public/assets/common/story/narrator-dialogue.css`)를 교체합니다. 세 챕터에서 이미 적용 중인 `.is-narrator-dialogue` 클래스로 동일한 나레이터 테마가 표시됩니다. 다른 캐릭터 대사창과 같은 외곽선·모서리 장식·왼쪽 화자 이름표·왼쪽 기호·본문·계속 기호 구조이며 검정/회색/은색 계열만 사용합니다.
3. 챕터 3 보스가 ESC를 직접 처리해 시뮬레이터용 종료 확인창을 띄우던 부분을 제거하고, 상위 챕터 3 스토리의 `STORY PAUSED` 창을 재사용합니다. 계속하기는 보스전으로 복귀하며, 메인화면 종료 시에는 보스전 체크포인트를 보존합니다.
4. 보스전 F7 테스트 기능은 그대로 유지하지만 챕터 1·2·3 스토리의 TEST 툴바/패널 디자인을 사용합니다. F6 스킵 버튼도 같은 스타일을 사용합니다.

## 적용

이 ZIP의 경로를 프로젝트 루트에서 그대로 덮어쓰도록 `APPLY_PATCH.cmd`에 ZIP을 드래그합니다. 프로젝트 루트 상대경로만 담았고 상위 폴더는 없습니다.

## 검사

- Chromium 922×960 논리 스테이지에서 CH1·CH2·CH3 일반 및 나레이터 대사창의 배치·크기 확인. CH2/CH3 일반 대사창 높이 차이 약 1px.
- V19 UI 정적 테스트 6개 통과, V17/V18 보스전 회귀 테스트 15개 통과.
- TypeScript 구문(변경 TSX 2개) 검사 및 ZIP 무결성, Git 공백 검사.
- 전체 Vite 빌드 및 전체 게임 통합 플레이는 의존성 설치 문제로 시행하지 못했습니다.
