# 호반우의 졸업 대작전 - 프롤로그 및 나레이터 통합 패치 V4

대상: 2026-11-03 AI_CONTEXT 기반 프로젝트 + 기존 폰트 통합 패치 / 챕터 1 균열 V3 계열

## 변경 내용

1. **챕터 1, 2, 3 나레이터 전용 대사창**
   - 화자 ID가 `narrator`일 때만 공통 스타일 `.is-narrator-dialogue` 적용
   - 캐릭터 초상화/이름표/빨간 전투 대사창을 숨기고 독립된 어두운 시네마틱 서사 패널로 교체
   - 금빛 세부 라인, 중앙 정렬, Noto Sans KR ExtraBold 800 적용
   - 호반우, 동료, 몬스터, 보스, 학생증 대사창은 기존 스타일 유지

2. **첨성대 코어 진입 연출**
   - `threshold` 이후 `core-approach` 약 3.1초를 새로 추가
   - 별빛 터널, 앞으로 흐르는 잔광, 입체 링, 중심 포털 효과를 지나 기존의 `core-reveal` 페이드 인과 연결
   - 기존 5초 코어 리빌 + 타이틀 등장 타이밍은 그대로

3. **실제 균열 기반 파편 낙하**
   - 격자 조각 대신 화면 중앙에서 생성된 균열의 각 주 경로를 파편 경계로 활용
   - 양쪽 균열 경로 + 화면 가장자리를 합쳐 다각형 파편을 구성
   - 파편의 회전축을 다각형 면적 중심에 배치하고 중력/회전/외향 분산 적용
   - 얇은 균열선과 이전 V3 균열 개수 설계 유지

4. **오프닝 크레딧 가림 수정**
   - `opening-credits-sequence`를 뷰포트 전체 최상위 시네마틱 이펙트 호스트로 표시
   - 이전 프롤로그 검은 배경 hold / 전체화면 시네마틱 정리 후 재생
   - 게임 로고, 제작자, 비공식 안내 기존 텍스트와 15초 길이 유지
   - 챕터 1 풀스크린 구간에서 기존 상단 연출 선택/대사 이동 버튼 및 React 테스트 이동 메뉴가 가려지지 않도록 상위 레이어 지정

## 검증
- JavaScript/TypeScript 소스 파싱 및 챕터 1 런타임 후킹 검사 통과
- 챕터 2/3 HTML 내 스크립트 파싱 통과
- 챕터 2/3 실제 HTML에서 나레이터 CSS computed style 확인
- 화면 7종 (922x960, 1920x1080, 3440x1440, 1080x1920, 800x600, 1600x900, 400x900)에서 다각형 파편 화면 덮임 검증
- 별도 브라우저 테스트에서 프롤로그 전체화면 버튼 이동/복구, 시네마틱 그림 출력, 크레딧 고정 레이어 표시 확인

## 적용 방법
압축을 풀어 게임 프로젝트 루트(`hobanwoo-graduation-operation`)에 파일 경로 그대로 덮어쓰십시오.
기존 `tools/chapter1_patch_runner/APPLY_PATCH.cmd`로 ZIP 드래그 적용이 지원되는 환경이라면 동일하게 적용해도 됩니다.
원본 ZIP 백업 후 적용을 권장합니다.

중요: 이번 ZIP은 **전체 프로젝트가 아니라 수정 파일만 포함하는 덮어쓰기 패치**입니다.
기존 프로젝트의 이미지·음원·기타 소스를 삭제하지 마십시오.

## 범위 및 제한
- 실제 프로젝트의 리소스 파일(코어 배경/게임 로고 등)과 의존성(`node_modules`)이 AI_CONTEXT에 포함되지 않아 완전한 게임 빌드/전체 플레이 검증은 수행하지 못했습니다.
- 시각 테스트는 코드에서 생성한 효과와 임시 합성 코어 배경으로 확인했습니다. 실제 원본 배경에서의 최종 시각 QA가 필요합니다.
