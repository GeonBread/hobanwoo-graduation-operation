# 호반우의 졸업 대작전 — Chapter 3 Boss V15

## 적용 전제
- 최신 **V14** 패치가 적용된 프로젝트에 덮어쓰십시오.
- ZIP 안의 `src/` 및 `tests/` 상대경로를 프로젝트 루트에 그대로 덮어씁니다.
- 기존 폭탄/아이템/Starfall Circuit BGM/V14 추방 공간 기능과 다른 챕터 파일은 변경하지 않습니다.

## 이번 변경 (사용자 요청 1~8)
1. 메인화면 사기 1의 버튼·로고 공격 경고선을 **검정 외곽+밝은 점선**으로 강화. 낮/저녁/밤(새벽) 배경에 따라 색 조정.
2. 메인화면 사기 2: 1·2·3장 일반 웨이브 몬스터 **총 35종** 중 무작위 혼합. 일반 **12마리**, 숙련 **25마리**. 배경은 **1.45초간 서서히 어두워진 다음** 몬스터 등장. 프로젝트 기존 에셋 경로 재사용.
   - 챕터 3 원본 10종은 자체 전투 로직을 유지합니다. 챕터 1·2의 몬스터 및 챕터 3 일부 3종은 공통 전장 AI(이동/조준탄)로 이식하여 이미지와 피격/폭탄 판정을 구현했습니다. 원본 웨이브 AI 전체를 그대로 재현한 것은 아닙니다.
3. 전장 밖의 손: 예고선 검정 테두리+선명한 밝은 경로. 공격 **최대 8묶음**.
4. 지나온 길이 접힌다: 기록한 경로를 두꺼운 밝은 선으로 표시, 각 선분을 순서대로 봉합하는 광선·공간 접힘 연출 강화. 앞서 접힌 경로의 흔적이 서서히 사라지고 다음 경로와 자연스럽게 연결. **3번까지만** 실행. 기본 보스 조준탄과 혼합.
5. 지오메트리 대쉬 비행: 회전 후 시작 전에 화면 중앙에 **아래로 향하는 큰 중력 화살표 3개**와 문구를 표시하고, 전투 시작 직전 제거. 실제 충돌 판정이 있는 바닥 가장자리에는 발광 오염 불꽃 추가.
6. 오염 액체 범람: 최대 수위에 도달한 **후에만** 발사되는 기존 순서를 유지하면서 탄환 밀도 증가(최고 숙련 0.66초마다 8발).
7. 탄환 접합: 최고 숙련의 연속 발사 **9묶음**, 더 빠른 간격(약 1.10초). 마지막 묶음 발사 직후 다음 패턴으로 전환 요청하며 링크 정리 지연 최소화.
8. 꼬리탄의 기존 수평 화살표는 공격 판정이 없는 단순 안내선이었습니다. 이번 버전에서는 **실제 대형탄이 진행할 가로 이동 경로**를 명확히 예고하고, 꼬리탄 분리 후엔 실제 탄환 발사 방향으로 선을 표시합니다. 화살표 자체는 공격 판정이 아니라 경고이며, 실제 탄환이 피격 판정을 갖습니다.
