# 챕터 1 프롤로그 균열 중앙 정렬 / 전체 화면 확산 수정 V2

## 수정된 문제
기존 버전에서는 균열 점 좌표를 모듈 초기 실행 시점의 922 x 960 크기로 고정 생성했습니다. 하지만 실제 프롤로그는 브라우저 크기에 맞춰 전체 화면 캔버스로 바뀌므로, 균열 시작점이 화면 중앙에서 벗어나고 균열의 끝이 화면 경계까지 도달하지 않았습니다.

## 변경 내용
- 균열 좌표를 항상 **현재 캔버스의 가로/세로 크기**를 기준으로 생성합니다.
- 모든 주 균열은 동일한 **화면 정중앙 (W/2, H/2)**에서 시작합니다.
- 네 모서리와 상/하/좌/우 각 3개 지점(총 16개 필수 경계 지점)에 도달하는 균열을 강제 생성하며, 끝점은 경계를 넘어서도록 설정했습니다.
- 추가 방향의 균열 및 중간에서 갈라지는 가지 균열을 더해 화면 곳곳으로 확산되도록 했습니다.
- 보라색 가장자리/밝은 테두리/검은 틈의 다층 효과는 유지했습니다.
- 배경 코어 흔들림은 유지하되, 균열 좌표에는 흔들림이 적용되지 않도록 분리했습니다.
- 균열과 파편화 구간에는 기존 하단 암부 그라데이션이 균열을 가리지 않도록 처리했습니다.
- 4초짜리 균열 연출 중 주 균열은 3.36초, 가지 균열은 3.75초 이내에 확산을 완료합니다.
- 이전 패치의 경북대학교 초반 전체 화면 프롤로그 설정은 유지됩니다.

## 적용 방법
다운로드한 ZIP을 기존 프로젝트 루트에 덮어씌우면 됩니다. 지난번 프롤로그 패치 ZIP 대신 이 V2 ZIP을 사용하세요.

## 검증
- `node --check` 구문 검사 통과
- 해상도 922x960, 1470x1056, 1850x832, 1920x1080, 1080x1920, 3440x1440, 320x568 등 7개에서 중앙 좌표, 네 모서리 및 12개 변 지점, 화면 경계 초과를 확인
- 캔버스 API 모의 렌더링 검사 통과 (각 해상도/시간 구간)
- 실제 게임 브라우저 시각 검증은 실행 리소스가 없어 실시하지 못함
